Exercise 1#

Variables, Comparators

Exercise: You are building a weather monitoring system, and would like to monitor certain parameters. Using Python variables, perform the following tasks:

  1. Create a variable storing today’s temperature in Celsius (you can use 4.2)

  2. Convert this temperature to Fahrenheit using the formula: \((\text{Celsius} * 9/5) + 32\)

  3. Store the temperature in Kelvin as well (\(\text{Kelvin} = \text{Celsius} + 273.15\))

  4. Create a boolean variable that indicates if it’s above freezing (above 0°C)

    • Hint: use an if statement, if celsius > 0:

    • If you are stuck, refer to the chapter Conditional statements

  5. Store the temperature unit “Celsius” as a string

  6. Create a variable that combines a number and a string to show “24.5 Celsius” (using the original Celsius value)

  7. Print out all values with appropriate labels using the print() statement.

The output might look like:

Temperature in Celsius: 18.3
Temperature in Fahrenheit: 214.3
Temperature in Kelvin: 999.65
Above freezing? False
Temperature reading: 24.5 Celsius

Solution#

celsius = 40.5
fahrenheit = celsius * 9/5 + 32
kelvin = celsius + 273.15

if celsius > 0:
    above_freezing = True
else:
    above_freezing = False
    
celsius_str = str(celsius)
temperature = str(celsius) + " Celsius"

print("Temperature in Celsius:", celsius)
print("Temperature in Fahrenheit:", fahrenheit)
print("Temperature in Kelvin:", kelvin)
print("Above freezing?", above_freezing)
print("Temperature reading:", temperature)

Temperature in Fahrenheit: 104.9
Temperature in Kelvin: 313.65
Above freezing? True

Variables, Casting, f-strings

Exercise: A data logger set up to record weather conditions records its readings as text.

The air pressure is "101325" (in Pa) and the air temperature is "15.0" (in °C).

  1. Store both readings as strings, and use type() to confirm their type.

  2. Convert the readings to floats, and convert the temperature to Kelvin using \(T = T_C + 273.15\).

  3. Compute the air density using the ideal gas law, \(\rho = p/(RT)\), with \(R = 287.05\) J/(kg K).

  4. Print the density to 3 decimal places using an f-string.

  5. Explain why int("15.0") raises an error, whereas float("15.0") does not.

pressure_str = "101325"
temperature_str = "15.0"
print(type(pressure_str), type(temperature_str))

pressure = float(pressure_str)
temperature = float(temperature_str) + 273.15

gas_constant = 287.05
density = pressure / (gas_constant * temperature)

print(f"Air density: {density:.3f} kg/m^3")

<class 'str'> <class 'str'>
Air density: 1.225 kg/m^3

int() can only convert a string that contains an integer. The decimal point in "15.0" tells Python that the value is not an integer, and causes a ValueError, whereas float() does not.

Exercise 4#

Mathematical functions, Precision, f-strings

A force of \(F = 850\) N acts at an angle of \(\theta = 35°\) to the horizontal.

  1. Compute its components, \(F_x = F\cos\theta\) and \(F_y = F\sin\theta\), and print them to 2 decimal places.

  2. Recover the magnitude from the components using \(\texttt{mag} = \sqrt{F_x^2 + F_y^2}\), and print it.

  3. Use magnitude == force to compare the values and print the result.

  4. Use isclose from the math library to check that this magnitude matches \(F\).

  5. Explain why isclose has to be used here, .

Hint: The trigonometric functions in math expect radians. Use mt.radians() to convert from degrees.

Solution#

force = 850
angle = mt.radians(35)

force_x = force * mt.cos(angle)
force_y = force * mt.sin(angle)
print(f"Fx = {force_x:.2f} N")
print(f"Fy = {force_y:.2f} N")

magnitude = mt.sqrt(force_x**2 + force_y**2)
print(f"Magnitude: {magnitude}")
print(f"Matches F? (exact) {magnitude == force}")
print(f"Matches F? (floating-point) {mt.isclose(magnitude, force)}")

Fx = 696.28 N
Fy = 487.54 N

Matches F? (exact) False
Matches F? (floating-point) True
